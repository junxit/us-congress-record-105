# MEASURE READ THE FIRST TIME--S. 2330

**Speaking:** Lott, Trent (L000447) [R-MS]

**Measures:** S. 2330

```
                  MEASURE READ THE FIRST TIME--S. 2330

  Mr. LOTT. Mr. President, I send a bill to the desk and ask that it be 
read a first time.
  The PRESIDING OFFICER. The clerk will read the bill for the first 
time.
  The legislative clerk read as follows:

       A bill (S. 2330) to improve the access and choice of 
     patients to quality affordable health care.

  Mr. LOTT. I now ask for a second reading, and I object to my own 
request.
  The PRESIDING OFFICER. The objection is heard.
  The bill will be read for the second time on the next legislative 
day.
  Mr. MURKOWSKI addressed the Chair.
  The PRESIDING OFFICER. The Senator from Alaska is recognized.
```
