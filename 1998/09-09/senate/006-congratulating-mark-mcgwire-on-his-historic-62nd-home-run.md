# CONGRATULATING MARK McGWIRE ON HIS HISTORIC 62ND HOME RUN

**Speaking:** Cochran, Thad (C000567) [R-MS]

```
       CONGRATULATING MARK McGWIRE ON HIS HISTORIC 62ND HOME RUN

  Mr. COCHRAN. Mr. President, I think before we start debate on that 
cloture motion, we should recognize the tremendous accomplishment of 
Mark McGwire who just broke Babe Ruth's home run record, Roger Maris' 
home run record and any other record that anyone has had for hitting 
home runs. The fact is that this is something we are all very happy to 
celebrate today, and we join with all Americans in congratulating Mark 
McGwire on this magnificent accomplishment.

                          ____________________
```
