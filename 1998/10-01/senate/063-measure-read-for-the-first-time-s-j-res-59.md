# MEASURE READ FOR THE FIRST TIME--S.J. RES. 59

**Speaking:** Hutchison, Kay Bailey (H001016) [R-TX]

**Measures:** S.J.Res. 59

```
             MEASURE READ FOR THE FIRST TIME--S.J. RES. 59

  Mrs. HUTCHISON. Mr. President, I understand that Senate Joint 
Resolution 59 which was introduced by Senator Gramm of Texas is at the 
desk, and I now ask for its first reading.
  The PRESIDING OFFICER. The clerk will read the resolution for the 
first time.
  The legislative clerk read as follows:

       A joint resolution (S.J. Res. 59) to provide for a Balanced 
     Budget Constitutional Amendment that prohibits the use of 
     Social Security surpluses to achieve compliance.

  Mrs. HUTCHISON. I now ask for its second reading, and I object to my 
own request.
  The PRESIDING OFFICER. The objection is heard.
  The resolution will be read the second time on the next legislative 
day.

                          ____________________
```
